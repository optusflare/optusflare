      MODULE 07

      OS Optimization Guides

      Pick your OS for a step-by-step performance pass. FPS ranges below are general, well-established estimates — not a measurement of your exact hardware.

      Windows optimization pass

      01
      Switch to the High Performance / Ultimate Performance power plan (Settings → Power & Battery).
      02
      Update GPU drivers directly from NVIDIA/AMD/Intel — not just Windows Update.
      03
      Disable unnecessary startup apps via Task Manager → Startup apps.
      04
      Turn on Game Mode and disable Xbox Game Bar overlay if you don't use it.
      05
      Set your GPU control panel's power management mode to "Prefer maximum performance."
      06
      Disable visual effects: Settings → System → About → Advanced → Performance → Adjust for best performance.
      Typical gain: +5 to +15 FPS in most modern titles

      Linux optimization pass

      Linux is already lean out of the box, so gains here are smaller and more about consistency (fewer stutters) than raw FPS.

      01
      Install your GPU's proprietary driver where available (NVIDIA proprietary, or Mesa updates for AMD/Intel) rather than relying on the default open driver.
      02
      Use a performance CPU governor: sudo cpupower frequency-set -g performance.
      03
      Enable GameMode (Feral Interactive's gamemoded) to auto-apply performance tweaks per game session.
      04
      If on Wayland and seeing stutter, try X11 as a quick comparison — some GPU/compositor combos still run smoother there.
      05
      Disable unnecessary background services with systemctl list-unit-files --state=enabled and trim what you don't need.
      Typical gain: +2 to +8 FPS, mostly smoother frame times

      macOS optimization pass

      01
      Close background apps eating CPU via Activity Monitor, sorted by % CPU.
      02
      Reduce motion and transparency: System Settings → Accessibility → Display.
      03
      Keep macOS and app updates current — Apple regularly ships GPU driver/Metal performance fixes.
      04
      Free up disk space — macOS slows noticeably under ~10-15% free storage.
      05
      For gaming specifically, use apps/ports built with Metal (native) over translation layers where possible.
      Typical gain: +5 to +12 FPS depending on the title
      MODULE 08

      Change Your OS

      A general, OS-agnostic guide to doing a clean install from a USB drive.

      01
      Download the official ISO file for the new OS you're installing, from its official source.
      02
      Get a USB flash drive (8GB+) — everything on it will be erased.
      03
      Use a tool like Rufus (Windows) or balenaEtcher (cross-platform) to flash the ISO onto the USB drive as a bootable installer.
      04
      Back up anything important first — a clean install can wipe your drive depending on the options you choose.
      05
      Restart your PC and enter BIOS/UEFI — usually by tapping F2, F10, F12, Del, or Esc right at boot (varies by manufacturer).
      06
      In BIOS, find Boot Order and move your USB drive to the top. If installing an OS other than Windows, you may also need to disable Secure Boot.
      07
      Save and exit — your PC will boot from the USB drive into the installer. Follow its on-screen setup.
      A clean install can permanently erase your drive. Back up your files first, and double-check you selected the correct drive during setup.

      For a fuller step-by-step with screenshots, see keemop.github.io.
